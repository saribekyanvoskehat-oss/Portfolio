## 01 — Armenian Proofreading Application

**A personal language-tool project focused on useful corrections without unnecessary changes.**

Armenian text checking needs more than dictionary lookup: a valid word may be wrong in context, while a proper name or inflected form may be incorrectly flagged. This project explores spelling, punctuation, and contextual suggestions for Armenian writing.

### Project components
- C# spelling engine with Hunspell dictionary support.
- Separate orthography and punctuation rule components.
- Trusted-word and word-frequency collections.
- Morphological and contextual cues for candidate corrections.
- A local AI second pass configured for Gemma 3 through a local AI service.

### My contribution
- Define Armenian correction requirements and construct challenging examples.
- Review suggestions for language accuracy and preservation of meaning.
- Identify false positives involving correct words, proper names, and word forms.
- Refine requirements and review AI-assisted implementation changes.

**Technology:** C#, .NET ecosystem, Hunspell, local language-model integration.  
**Status:** Personal development project; accuracy remains under iterative review. No production accuracy benchmark is claimed.

**What this demonstrates:** Armenian language judgment, error analysis, attention to false corrections, and practical collaboration with AI development tools.
